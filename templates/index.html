📜 Game Rules

  • Convert each binary number to decimal.
  • Calculate the sum of every row.
  • Calculate the sum of every column.
  • Calculate the XOR of the main diagonal.
  • Find the largest row sum (Rmax).
  • Find the largest column sum (Cmax).
  • Submit the answer in the format: Rmax-Cmax-XOR
  • The first correct submission wins the round.
